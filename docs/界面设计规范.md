# SpectroscopicAnalysis 上位机界面设计规范

> 本规范是 WPF 界面的**强制风格规则**。UI 相关代码与本规范冲突时，以本规范为准。
> 关联文档：[开发规范](./开发规范.md) · [上位机任务清单](./上位机任务清单.md)

---

## 1. 风格定位

- **浅色简洁风**（类现代 SaaS 后台）：白底卡片 + 轻彩色点缀，实验室/办公环境观感舒适，信息密度较高。
- 设计基准分辨率 **1920×1080**；最小支持 **1366×768**，采用自适应缩放布局（Viewbox/网格比例），不锁定固定像素。
- 界面全中文。

## 2. 依赖登记（按 AGENTS.md 新依赖登记规则）

| 依赖 | 版本 | 用途 | 选型理由 |
|---|---|---|---|
| HandyControl | 最新稳定版（NuGet） | WPF 控件库 | 控件丰富（DataGrid/表单/对话框/通知），社区成熟，中文文档；主题色可完全覆盖为本规范色板 |

## 3. 色彩系统

所有颜色**必须**定义在 `Themes/Colors.xaml`，控件一律通过 `Brushes.xaml` 资源引用；禁止在 XAML 或代码中硬编码色值。

### 3.3 状态色（语义固定，禁止挪作他用）

状态色与任务清单状态机枚举、开发规范 11.2 报警分级一一对应：

## 4. 字体规范

- 字体：`Microsoft YaHei UI`（中文优先，数字混排兼容）；全局默认 14px Regular。
- 字号阶梯（资源键 `Typography.xaml`）：

| 用途 | 字号 | 字重 |
|---|---|---|
| 大数值仪表（强度/浓度/计数） | 28–32px | SemiBold |
| 页面标题 | 20px | SemiBold |
| 区块/卡片标题 | 16px | SemiBold |
| 正文 | 14px | Regular |
| 辅助说明/时间戳 | 12px | Regular（最小字号，低于 12px 禁止） |

- 正文与背景对比度 ≥ 4.5:1；状态文字必须同时用**颜色 + 图标/文字标签**表达，不得仅靠颜色区分。

## 5. 布局规范

```
┌──────────────────────────────────────────────┐
│ 顶栏 56px：产品名 | 系统模式切换 | 心跳/通信状态 | 时间 | 用户 │
├────────┬─────────────────────────────────────┤
│ 左栏    │  内容区（卡片流）                      │
│ 240px  │  ┌─卡片─┐ ┌─卡片─┐                  │
│ 导航    │  │      │ │      │                  │
│ ────── │  └──────┘ └──────┘                  │
│ 设备状态 │  ┌────────────────┐                │
│ 固定栏  │  │ 报警面板（底部常驻）│               │
└────────┴─────────────────────────────────────┘
```

- 顶栏（56px）：产品名 + **系统模式**（Auto/Manual/Maintenance/Emergency 当前值高亮）+ PLC 心跳/通信状态灯 + 当前时间 + 登录用户。
- 左栏（240px）：上半部导航（生产分析 / SCT 管理 / 样品档案 / 系数管理 / 日志报警 / 设置），下半部**设备状态固定区**：SafetyOK、RobotReady、SparkStandReady、GNR、铣床五个状态灯常驻可见。
- 内容区：卡片式分区，圆角 8px、轻阴影（Y=2, Blur=8, 透明度 8%）。
- 间距体系：4px 基数（4/8/12/16/24/32），卡片内边距 16px，卡片间距 12px。
- **急停按钮全局常驻**：顶栏右侧，大尺寸（≥48px 高）、`Color.Status.Emergency` 高对比、圆形图标按钮。

## 6. 核心界面组成规则（对应任务清单）

| 界面区块 | 规则 |
|---|---|
| 系统模式切换区 | 四个模式单选高亮；切换必须弹出双方确认对话框（通信规范要求 PLC 确认）；Emergency 态整页顶部显示深红警示条 |
| 设备状态区 | 每设备一行：名称 + 状态灯 + 最近心跳时间；状态灯用 3.3 状态色 |
| 任务/样品表格 | HandyControl DataGrid；列含 SampleID、类型、状态、厚度、使用次数、当前步骤；状态列用徽章（颜色 + 文字） |
| SCT 状态展示 | 当前 SCT 子状态进度条（Selecting→…→Returning）；展示触发原因、所用样品、系数变更前后值 |
| 结果展示 | **原始强度/浓度与校正后结果双列并显**（数据规范硬性要求），校正列主色高亮 |
| 报警面板 | 底部常驻，四级分级展示（见第 7 节）；未确认报警置顶并计数 |

## 7. 报警面板四级展示（衔接开发规范 11.2 错误链路）

| 级别 | 颜色 | 图标 | 提示音 | 交互 |
|---|---|---|---|---|
| 提示（Info） | `Color.Status.Info` | ℹ | 无 | 自动消失，入日志 |
| 警告（Warning） | `Color.Status.Warning` | ⚠ | 单次提示音 | 需人工确认 |
| 故障（Fault） | `Color.Status.Failed` | ✖ | 循环提示音（可静音） | 需人工确认 + 处置 |
| 急停（Emergency） | `Color.Status.Emergency` | ⛔ | 持续报警音 | 需故障复位流程（二次确认） |

- 每条报警必含：时间、错误码、消息、来源设备、TaskID/SampleID 上下文（与结构化日志字段一致）。

## 8. HandyControl 使用约定

- 选用范围：Button、DataGrid、TextBox/ComboBox/DatePicker、Dialog、Notification、Badge、StepBar（SCT 进度）、Pagination。
- 主题：引入 HandyControl 浅色主题后，**必须用本规范色板覆盖其主题资源**（Primary 等），保持全局浅色一致性。
- 危险操作（急停复位、模式切换、样品禁用、系数手动修改）**必须二次确认对话框**，确认按钮用 `Color.Danger`。
- 操作反馈：成功用轻量 Toast/Notification（Info 色），禁止弹窗打断正常节拍。

## 9. XAML 工程约定

```
src/SpectroscopicAnalysis.Host/Themes/
├── Colors.xaml        # 3.x 全部颜色（Color.* 键）
├── Brushes.xaml       # 仅引用 Colors.xaml 生成 Brush.* 键
├── Typography.xaml    # 字号/字重样式（4 节阶梯）
└── Styles.xaml        # 控件样式（基于 HandyControl 扩展）
```

- 资源键命名：`Color.语义`、`Brush.语义`（如 `Brush.Status.Running`）、样式键 PascalCase 用途命名。
- 控件颜色/字号**一律 DynamicResource 引用**；**禁止** XAML 内联 Hex 色值、禁止代码后置 new SolidColorBrush(硬编码)。
- 新样式先查 Styles.xaml 是否已有近似样式，避免重复定义。

## 10. MVVM 绑定约定

- ViewModel **禁止**返回 `Brush`/`Color`/字号等视觉属性；只暴露状态枚举与业务值。
- 枚举 → 颜色/图标的映射统一用 Converter（如 `TaskStatusToBrushConverter`、`SampleStatusToBadgeConverter`），集中放 UI 层 `Converters/`，映射表内部引用 Themes 资源。
- 视图模型状态枚举命名必须与任务清单第 7 节状态机枚举一致。

## 11. 交互与文案

- 全中文文案；术语与任务清单一致（"设置样/控制样/类型标准化样"、"标准化/测高/铣削"），不自造同义词。
- 模式切换、急停复位、样品禁用等操作必须二次确认，确认框文案说明**后果**（如"切换 Auto 前将校验样品位置一致性"）。
- 加载/等待（如等待 PLC 放置）用进度指示 + 当前步骤文字，禁止无反馈死等。
