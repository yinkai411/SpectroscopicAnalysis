# 上位机（Host PC）任务清单

> 依据文档：《自动直读光谱系统工艺流程和系统设计要求101.pdf》（GNR-ABB-Siemens 自动化样品分析系统 技术手册与控制系统编程指导，共 52 页）整理。
>
> 本清单作为 SpectroscopicAnalysis 上位机软件开发的需求依据。文中 `Pn` 为原文档页码。

## 文档定位

文档明确定位：**Host PC（上位机）是主控计算机**，承担"样品档案、SCT 策略决策、流程编排、结果校正与数据管理"（P1）；GNR 仪器只负责激发与原始数据输出，**校正逻辑全部由 Host PC 完成**。

## 一、总体职责边界（P1–P2）

| 事项 | 上位机职责 | 非上位机职责（PLC/机器人执行） |
|---|---|---|
| 流程控制 | 策略决策、流程编排、任务下发 | 底层实时控制、安全互锁 |
| 分析数据 | 校正计算、结果判定、数据管理 | GNR 仅输出原始强度/浓度 |
| 设备协调 | 协调机器人/铣床/激发台/光谱仪 | 具体动作执行 |

## 二、通信接口任务（P2、P31–P36、P48–P51）

1. **Host PC ↔ 西门子 PLC**（**当前采用 Modbus TCP**，OPC UA 作为后续升级备选，见下方"通信方案选型说明"）
   - 任务下发（TaskCommand：TaskID / TaskType / SampleID / RackPosition / GripHeight / NeedMill / MillProgram / SparkCount / Priority）
   - 状态反馈接收（TaskStatus：Status / CurrentStep / ErrorCode / ActualGripHeight 等）
   - **结构体 → 保持寄存器块映射**（定长、固定偏移，双方按映射表联调）；SampleID / RackPosition 等字符串字段**改为数字编号**，规避 Modbus 寄存器编码问题
   - 状态获取采用**轮询 + 变化检测**（Modbus 无订阅机制）：TaskStatus、Robot.Ready、SparkStand.Ready、SafetyOK 等状态位
   - 命令握手采用**命令寄存器写值 + 应答寄存器读值**模拟方法调用
   - 心跳维护（递增计数寄存器，1–2 秒）、模式切换双方确认、通信中断超阈值进入安全状态
2. **Host PC ↔ GNR 光谱仪**（TCP，协议号 100–140）
   - `CYCLE_START_REQUEST`（ID_CYCLE=1 生产分析 / 2 标准化 / 3 控制样）
   - `SAMPLE_POSITIONED`、`RESULT_REQUEST`、`RESULT_DATA_REQUEST`（扩展接口，获取强度/浓度）
3. **Host PC ↔ 铣床 PLC**：制样任务协调（P2；本次未配铣床，软件需**预留**该流程，人工上样后直接进视觉，其余流程不变，P4）
4. **Host PC ↔ 注册终端 / MES / 用户界面**：样品注册录入、结果上报（P1–P2）

### 通信方案选型说明（当前决策）

**当前阶段采用 Modbus TCP**，理由：

- 无授权成本（OPC UA Server 需按 CPU 购买西门子运行授权）
- 若现场为 S7-1200，无内置 OPC UA Server，Modbus TCP（MB_SERVER 指令）开箱即用
- 开发与联调周期短（Python `pymodbus`，读写寄存器即可打通）

**OPC UA 保留为升级路径**：

- 原始需求文档的 OPC UA NodeSet 设计（P44–46）仍保留作参考
- `DeviceInterface` 模块保持抽象接口（`SendTask / GetTaskStatus / MeasureHeight / NotifyTaskEnd`），OPC UA 与 Modbus TCP 作为可替换实现，业务层代码不受影响，后续可平滑切换

**Modbus TCP 安全约束**：协议无认证、无加密、明文传输，PLC 通信网络必须与其他网络隔离（独立 VLAN / 防火墙白名单，仅允许上位机访问 PLC 通信端口）。

## 三、样品档案与数据库管理（P3、P12–P21）

- 建立并维护 5 张核心表：
  - **SCT_Sample**（样品档案）
  - **SCT_CertifiedValue**（标准值）
  - **CorrectionCoefficient**（校正系数，版本化）
  - **SCT_OperationLog**（操作日志）
  - **ControlLimit**（控制限）
- **入库初始化**：录入基本信息/标准值/初始厚度/最大使用次数/最小厚度阈值；位置与软件记录绑定（P13）
- **使用次数与厚度控制**（P13–P14）：每次激发 UsageCount+1；达阈值 → 标记 NeedMeasure → 下次先测高 → 更新当前厚度 → 低于 MinThickness 则 Disabled 并报警更换，否则**重算抓取高度**
- **样品状态机维护**：Normal / NeedMeasure / Warning / Disabled 及其转移（P22）

## 四、流程编排（WorkflowOrchestrator）（P3–P6）

生产样品全流程中上位机负责的环节：

1. 样品注册（本机或接收外部系统）
2. 接收进样到位传感器通知
3. 向 PLC 下发抓取任务（含抓取高度）
4. 接收视觉选点坐标（可选）
5. **SCT 插入判断**——决定是否优先执行标准化/控制样
6. 触发 GNR 激发并读取结果
7. 应用修正系数计算最终浓度、判定合格性（超差报警或按策略处理）
8. 归档管理：标签打印、归档盒放置指令、更新样品档案与轨迹日志
9. 循环下一件

需实现三类状态机（P6）：

- **系统模式**：Manual / Auto / Maintenance / Emergency
- **任务状态**：Idle → Registered → Preparing → Milling → Placing → Analyzing → Archiving → Completed / Failed
- **SCT 子状态**：Selecting → Retrieving → MeasuringHeight → Milling → Analyzing → UpdatingCoeff → Returning

## 五、SCT 策略引擎（P6、P9、P14–P16、P26、P51）

1. **设置样（标准化）触发判断**：定时（班次开始/固定间隔）、切换自动模式、控制样超差、用户/外部请求、类型标准化后漂移过大
2. **设置样选择规则**：SampleType=SettingUp 且 Status=Normal、匹配分析方法；多个时选使用次数最少或轮询；无可用 → 报警并暂停分析
3. **控制样插入**：按分析数量（每 10–20 个）或时间间隔；按合金类型/含量梯度匹配；多块轮换
4. **控制样判定与超差闭环**：结果落在控制限（±2σ/百分比/绝对值）内 → 继续；超差 → 触发设置样标准化 → 标准化后再分析同一控制样验证 → 通过恢复生产，仍失败 → 报警并暂停自动模式
5. **类型标准化**：合金类型切换或期限届满时触发，按 AlloyType 精确匹配标样
6. **优先级调度**（P29）：急停/故障恢复 > 超差触发的标准化 > 控制样检查 > 类型标准化 > 生产样品分析 > 归档

## 六、校正计算引擎（CorrectionEngine）（P6–P7、P17–P19、P26–P28、P36–P37、P47）

- 线性模型 `C = a·I + b`（或强度比 `C = a·(I元素/I内标) + b`）
- **单点标准化**：`a_new = a_old × C标准/C测量` 或强度比法 `k = I标准期望/I当前测量`；**两点标准化**：高低标样重拟合斜率截距
- **多元素系数矩阵**：每元素独立系数；支持**干扰校正（IEC）**——迭代 2–3 次求解
- **干扰系数回归工具**（无厂家系数时）：8–15 个标样最小二乘回归，R²>0.95 可用（文档建议作为离线标定功能）
- **系数应用原则**：生产样品结果 = 最新系数计算值；**必须同时保存原始数据与校正后数据**；系数版本化管理（IsCurrent/Version、旧版本归档）；变更需完整审计日志（前后值、时间、原因、来源样品、操作者）

## 七、视觉模块（VisionModule）（P2–P3、P5–P6）

- 海康相机图像处理：表面识别、**激发点规划**并将坐标回传 PLC/Host PC
- 高度检测（配合测高流程更新厚度）
- 抓取状态/位置确认（可选但推荐）

## 八、抓取与放置参数计算（P7、P14、P31）

- 下铣头场景：以"分析面以下固定距离"为基准计算 GripHeight 随任务下发
- 标样变薄后：根据测高结果**动态重算抓取点**，保证分析面准确到位

## 九、安全与模式管理（P8、P33）

- 自动模式下安全门锁定；急停后必须故障复位才能恢复
- SCT/漂移校正执行期间暂停生产样品分析
- **样品实际位置必须与软件记录一致，否则拒绝切入自动模式**
- 心跳监测、通信中断进入安全状态、错误码分类处理（1001 抓取失败、1002 未检测到样品、2001 下压异常、3001 安全门、9001 急停）
- **Modbus TCP 通信网络隔离**：协议无认证/加密，须独立 VLAN / 防火墙白名单（详见第二节选型说明）

## 十、并发控制（P28–P31）

- 优先级任务队列 + 资源互斥锁（RobotLock / SparkStandLock / CoefficientLock 读写锁 / SampleArchiveLock）
- 系数读写分离 + 版本号，避免结果计算读到中间状态
- 手动操作与自动任务的模式锁

## 十一、日志与报警审计（P8、P16、P20–P21）

必须记录：每步动作起止时间、SCT 触发原因、控制样超差详情、系数变更前后对比、厚度变化历史、所有报警与人工干预、（可选）机器人动作轨迹。

## 十二、建议模块划分与实施顺序（P6–P7、P17、P33、P51）

| 模块 | 职责 |
|---|---|
| SampleManager / SCTSampleManager | 档案、位置、次数、厚度、状态 |
| SCTStrategyEngine | 触发判断、样品选择、优先级调度 |
| WorkflowOrchestrator | 流程状态机、设备编排 |
| CorrectionEngine | 系数计算、应用、版本管理 |
| DeviceInterface | PLC / GNR / 铣床通信封装（PLC 当前实现 Modbus TCP，预留 OPC UA 升级） |
| VisionModule | 图像处理、选点、测高 |
| LogAndAlarm / AuditLogger | 日志与报警 |

**实施优先级**：

1. **Modbus TCP 任务下发与状态反馈**（寄存器映射 + 轮询，打通 Host PC 与 PLC）
2. GNR 协议（100–140）基本激发流程
3. RESULT_DATA_REQUEST 扩展
4. 系数计算（先单元素再干扰校正）
5. 干扰系数回归工具（离线）
